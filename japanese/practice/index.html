练习：间隔重复

每天 10–15 分钟。算法会记住你每张卡片掌握得怎样，把快要忘的排在前面——比一遍遍从头背整张表省时间得多。假名之外，还可以练初级上（N5）的动词、形容词和汉字例词。

FSRS 算法（Anki 同款）数据只存在你的浏览器每天新卡上限 15 张

它是怎么安排复习的

  • 两种模式分开记录。「认读」练看到字形就想起读音，「听辨」练听到声音就想起字形——这是两种不同的记忆，各自安排复习。
  • 自动评分。答错 = 「重来」，几分钟后在本轮再出现；答对但用时超过 6 秒 = 「困难」；答对 = 「良好」。算法据此计算下次复习时间：越熟间隔越长。
  • 算法是 FSRS。由开源组织 Open Spaced Repetition 开发、Anki 也采用的间隔重复算法；本站使用其官方 TypeScript 实现 ts-fsrs 6.0.0，目标记忆保持率设为 90%。
  • 认读模式的答案：假名卡片打罗马字，黑本式（shi / chi / tsu / fu / ji）和训令式（si / ti / tu / hu / zi）都算对；「を」答 o 或 wo、「ん」答 n 或 nn 都算对。N5 词汇卡片打读音：可以直接用日语输入法打假名，也可以打罗马字（按输入法的规则换成假名再比对，如 gakkou → がっこう）。
  • 隐私：学习记录只保存在你这台设备的浏览器（localStorage）里，不上传任何地方；清除浏览器数据会一并清除。

想练长短音、清浊、声调这些听力上的区分，去各课末尾的「听辨练习」。
