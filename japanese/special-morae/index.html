促音·拨音·长音

日语的节奏单位是「拍」（モーラ）。促音（小写的っ）、拨音（ん）、长音这三种「特殊拍」各自占一整拍——少发一拍，词就变了：おばさん（阿姨）多拖一拍就成了おばあさん（奶奶）。

先弄清「拍」

一拍大约是一个假名的长度（拗音如「きょ」算一拍）。日本人感觉每拍长度差不多——实际测量并不严格相等，但学的时候按「大致等长」来把握。关键是：特殊拍也算一拍，不能吞掉、不能缩短。

词按拍切分拍数
とうきょう（東京）と｜う｜きょ｜う4
にっぽん（日本）に｜っ｜ぽ｜ん4
がっこう（学校）が｜っ｜こ｜う4
しんぶん（新聞）し｜ん｜ぶ｜ん4
练节奏的小技巧

只按「一拍一下」去拍手，容易把每个音都念得一样长、像机器人。日语教育研究者戸田貴子（早稻田大学）建议把特殊拍和前一拍合成「两拍一组」来练，更接近自然说话：とう｜きょう、しん｜ぶん——每组占两拍；きっ｜て 则是两拍一组加上一拍，共三拍，末尾的「て」不要拖长。

促音「っ」：停顿一拍

写作小一号的「っ」（片假名「ッ」）。发音时口型做好下一个辅音的准备，停住一拍，再发出来。它本身没有声音（擦音前则是把 s、sh 拉长），但占一拍时间。罗马字一般把后面的辅音字母写两遍：きって kitte；但各方案在「っち」上不同——修正黑本式写 tch（matcha），2025 年新《ローマ字のつづり方》写 cch（maccha）。输入法里重复辅音即可打出「っ」，也可以用 xtu 或 ltu 单独打。

拨音「ん」：一拍鼻音，读法随后面的音变

「ん」永远自成一拍。它的实际发音会自动向后一个音靠拢——这是自然发生的，不用刻意去学，但知道了能听得更准：

「ん」后接元音：最容易错的地方

「きんえん」（禁烟）是 き・ん・え・ん 四拍，ん 后面的 え 不能和 n 连成「ね」——否则就成了「きねん」（纪念，三拍）。打字时也要把 ん 和后面的元音分开：kinnenn 或 kin'en。

长音：把元音拖长一拍

长音就是同一个元音持续两拍。平假名的写法由文化庁《現代仮名遣い》规定：

段写法例
あ段加「あ」おかあさん、おばあさん
い段加「い」おじいさん、にいさん
う段加「う」くうき（空気）、きゅうり
え段加「え」ねえさん、ええ（是的）
お段加「う」おとうさん、ありがとう、がっこう

两个例外要记住：

  • え段 +「い」：大量汉语词写成「えい」，例如 せんせい（老师）、えいが（电影）、とけい（钟表）。官方说明读成长音 [eː] 或读成 e-i 都可以；日常说话里多读成长音。
  • お段 +「お」：少数词按历史写法写「お」，例如 おおきい（大）、とおい（远）、こおり（冰）、おおい（多）、とおる（通过）、とお（十）。这些只能逐个记。

片假名的长音一般用长音符「ー」：コーヒー、ビール（第 5 课）。

长短不分，意思就错

普通话里元音长短不区分意思，所以中文母语者很容易把长音读短（おばあさん → おばさん）或把短音拖长。练习时可以用手指数拍：おばあさん 是 お・ば・あ・さ・ん 五拍。
