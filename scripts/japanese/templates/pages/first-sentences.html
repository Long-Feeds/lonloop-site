句型：AはBです

{{ sent("s-tanaka") }}{{ sent("s-kore-hon") }}
  • は：提示「主题」——「说到 A 嘛」。作助词时写は、读 wa。
  • です：礼貌地表示「是」。句末的「す」常常轻得几乎听不见（元音清化），听音频注意这一点，但不要刻意吞掉整个音节。
  • 日语句子的谓语在最后，这和中文语序不同（第 0 课讲过 SOV）。

疑问：句末加「か」

{{ sent("s-kore-nan") }}{{ sent("s-gakusei-ka") }}

把「か」加在句末就成了疑问句，语序不变。礼貌的疑问句在书面上用「。」结尾而不是「？」也很常见。「〜さん」接在别人的姓或名后面表示尊称（相当于「先生／女士」），不能用在自己身上。

「の」：……的

{{ sent("s-watashi-kasa") }}

「{{ m.jp("私の傘") }}」= 我的伞。「これ・それ」分别是「这个」（离说话人近）和「那个」（离听话人近）。

回答：はい／いいえ

{{ sent("s-hai-gakusei") }}{{ sent("s-iie") }}

否定「不是」用「じゃありません」，更正式、书面的说法是「ではありません」（意思相同）。

完整的自我介绍

{{ sent("s-hajime") }}{{ sent("s-tanaka") }}{{ sent("s-chugoku") }}{{ sent("s-kaishain") }}{{ sent("s-yoroshiku") }}

把「田中」换成你的名字就能用。中文名字在日语里常见两种念法：按日语汉字音读（例如「王」读おう），或按中文发音用片假名写（例如ワン）。你可以自己选，选定之后统一用一种。

{% call m.callout("入门完成之后") %}

学到这里，你已经会读写全部假名、知道日语的发音和声调规律，也能说出第一段完整的话。下一阶段（初级上，约 N5）会系统学习动词、形容词和更多助词。每天的间隔重复练习请继续——假名要熟到不用想就能读出来。
