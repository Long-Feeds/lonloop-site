两种形容词

い形容词な形容词
基本形高い　新しい　おいしい静か　便利　きれい
修饰名词高い 本（直接接名词）静かな 部屋（中间加「な」）
怎么变词尾的「い」自己变化词干不变，变的是后面的 だ／です
{% call m.callout("看结尾的「い」不可靠", "warn") %}

きれい（漂亮）、有名（ゆうめい，有名）、嫌い（きらい，讨厌）的读音都以「い」结尾，却是な形容词：说「きれいな花」「有名な人」，否定说「きれいじゃない」，不说「きれくない」。最可靠的判断方法是记住它修饰名词时要不要加「な」。（形态分析器 UniDic 也把这三个词分析为形状词，即な形容词。）

{% endcall %}

い形容词

去掉词尾的「い」，接上不同的词尾：

形式变法例（高い）
现在肯定基本形高い
现在否定〜い → 〜くない高くない
过去肯定〜い → 〜かった高かった
过去否定〜い → 〜くなかった高くなかった
て形（连接）〜い → 〜くて高くて
{% if "いい" in AW %}{% set F = B5.form_ids(AW["いい"]) %} {% call m.callout("唯一的不规则：いい（好）") %}

「いい」的变化全部从它的另一种说法「よい」来：{{ F.nai.w }}（不好）、{{ F.katta.w }}（过去好；口语里也常说「太好了」）、{{ F.nakatta.w }}、{{ F.te.w }}。不说「いくない」「いかった」。

い形容词的敬体（礼貌说法）

在普通体后面加「です」就是敬体。否定还有一种说法「〜くありません」，两种都对，后者稍正式。

形式敬体
现在肯定高いです
现在否定高くないです ／ 高くありません
过去肯定高かったです
过去否定高くなかったです ／ 高くありませんでした
{% call m.callout("常见错误：「高いでした」", "warn") %}

い形容词的过去要在词尾上变：高かったです。把「高いです」的「です」直接换成「でした」（×高いでした）是初学者最常见的错误之一。名词和な形容词的过去肯定才是把「です」换成「でした」（学生でした、静かでした）。

な形容词

な形容词的词干不变，变化的是后面的「だ」（普通体）或「です」（敬体）——除了修饰名词时用「な」（名词用「の」），变法和名词句「学生です／学生じゃありません」一样：

形式普通体敬体
现在肯定静かだ静かです
现在否定静かじゃない静かじゃありません ／ 静かではありません
过去肯定静かだった静かでした
过去否定静かじゃなかった静かじゃありませんでした
修饰名词静かな 部屋
て形（连接）静かで

「じゃ」是「では」的口语形，两者意思相同；书面和正式场合多用「では」。

例句

{{ s5("a-s-1") }}{{ s5("a-s-2") }}{{ s5("a-s-3") }}{{ s5("a-s-4") }}{{ s5("a-s-5") }}
  • 好き・嫌い・上手・下手的对象用「が」：猫が好きです（我喜欢猫）、歌が上手です（歌唱得好）。
  • 上手是夸别人的词，说自己时一般不用（自己擅长常说「得意」，以后会学）。
  • て形用来连接两个形容词：広くて明るい（又宽敞又明亮）、静かできれい（又安静又漂亮）。
{% call m.callout("汉字词，意思不一定和中文一样", "zh") %}

丈夫（じょうぶ）在日语里是「结实、耐用；（身体）健壮」，不是中文的「丈夫（配偶）」。大切（たいせつ）是「重要、珍贵」。大丈夫（だいじょうぶ）是「没关系、不要紧」。
