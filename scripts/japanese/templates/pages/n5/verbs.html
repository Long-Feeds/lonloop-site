动词长什么样

词典里查到的动词形式叫辞书形，它一定以「う段」的假名结尾：う く ぐ す つ ぬ ぶ む る。例如 {{ m.jp("書く") }}（かく，写）、{{ m.jp("話す") }}（はなす，说话）、{{ m.jp("食べる") }}（たべる，吃）。

动词按变化方式分成三类。叫法不统一：面向外国人的初级教材常叫「第Ⅰ类、第Ⅱ类、第Ⅲ类」（或一类、二类、三类），日本的国语语法叫「五段、一段、カ变·サ变」，本页两种都标出来。

三类动词怎么判断

类别特征例子
第Ⅰ类
五段动词		不以「る」结尾的动词，全部属于这一类；以「る」结尾、而「る」前面是 あ段・う段・お段 的，也属于这一类書く 話す 待つ 読む 遊ぶ 買う
分かる（か=a）乗る（の=o）
第Ⅱ类
一段动词		以「る」结尾，「る」前面是 い段 或 え段見る（み=i）起きる（き=i）
食べる（べ=e）寝る（ね=e）
第Ⅲ类
不规则动词		只有两个：する、来る（くる）；「名词＋する」（如 勉強する）也按 する 变化する 来る 勉強する

判断步骤：

  1. 是 する 或 来る（或「名词＋する」）吗？→ 第Ⅲ类。
  2. 不以「る」结尾？→ 第Ⅰ类。
  3. 以「る」结尾：看「る」前一个假名的元音。是 a / u / o → 第Ⅰ类；是 i / e → 大多数是第Ⅱ类，但有一批例外属于第Ⅰ类，只能记住（下表）。
{% call m.callout("要看读音，不要看汉字", "warn") %}

「る」前面的假名常常藏在汉字里：見る 是 み・る，寝る 是 ね・る，着る 是 き・る，出る 是 で・る——都是 i 段、e 段，所以是第Ⅱ类。判断时请先把读音写出来。

ます形：礼貌的说法

对不熟的人、在正式场合说话用ます形（敬体）。它有四种形式：

形式意思例
〜ます现在·将来肯定（也表示习惯）毎日 書きます／明日 書きます
〜ません现在·将来否定書きません
〜ました过去肯定書きました
〜ませんでした过去否定書きませんでした

变法（先做出「ます」前面的部分，叫「ます形词干」）：

  • 第Ⅰ类：词尾的 う段 假名换成同一行的 い段，再加ます：書く→書きます、話す→話します、待つ→待ちます、読む→読みます、帰る→帰ります。
  • 第Ⅱ类：去掉る，加ます：食べる→食べます、見る→見ます。
  • 第Ⅲ类：する→します、来る→来ます（きます）。

日语的「〜ます」既表示现在的习惯，也表示将来：明日 行きます（明天去）。没有单独的「将来时」。

{{ vtable(["masu", "masen", "mashita", "masendeshita"], ["〜ます", "〜ません", "〜ました", "〜ませんでした"]) }}

辞书形与ない形：普通体的肯定和否定

朋友、家人之间说话用普通体（常体）。普通体的现在肯定就是辞书形，现在否定是ない形：

  • 第Ⅰ类：词尾的 う段 换成 あ段，加ない：書く→書かない、読む→読まない。词尾是「う」的变成「わ」：買う→買わない、会う→会わない（不是「買あない」）。
  • 第Ⅱ类：去掉る，加ない：食べる→食べない。
  • 第Ⅲ类：する→しない、来る→来ない（こない，注意读音变了）。
  • 例外：ある 的否定就是 ない（没有「あらない」）。
{{ vtable(["nai"], ["ない形"]) }}

て形与た形：音便

て形本身没有时态，它是许多句型的「零件」：连接两个动作、请求（〜てください）、正在进行（〜ています）等，后续批次逐个学。た形是普通体的过去肯定。两者变法完全相同：把て形的「て／で」换成「た／だ」就是た形。

第Ⅰ类变て形时，词尾会发生「音便」——这是最需要背的部分：

词尾て形／た形例
う・つ・る→ って／った（促音便）買う→買って　待つ→待って　帰る→帰って
む・ぶ・ぬ→ んで／んだ（拨音便）読む→読んで　遊ぶ→遊んで　死ぬ→死んで
く→ いて／いた（イ音便）書く→書いて　聞く→聞いて
ぐ→ いで／いだ（イ音便）泳ぐ→泳いで
す→ して／した（没有音便）話す→話して　貸す→貸して
例外行く → 行って／行ったく结尾，却变成促音（不是「行いて」）
第Ⅱ类去る＋て／た食べる→食べて　見る→見て
第Ⅲ类して／した、来て／来た来て 读 きて

表中「促音便」「イ音便」等名称，形态分析器 UniDic 也是这样记录的：本页每个て形、た形都经它反向分析，确认音便类型与规则一致（例如「行って」被分析为「行っ」连用形·促音便＋「て」）。

  • 名詞＋を＋動詞：「を」标出动作的对象（读 o），详见第 3 课。
  • 〜てください：用て形请别人做某事，「書いてください」= 请写。
  • 知る：「知っています」才表示「知道、认识」；否定一般说「知りません」（「知っていません」不自然）。

几个小提醒

  • 言う按《現代仮名遣い》写作「いう」，但实际发音是「ゆう」（UniDic 记录的发音也是ユー）。听音频时注意这一点，书写仍然写「いう」。
  • ある／いる都表示「在、有」：东西、植物用 ある，人和动物用 いる（存在句在后续批次系统讲）。
  • 前面用什么助词，由动词决定：分かる・ある・いる 的对象或主语用「が」；乗る・会う・入る 用「に」（中文母语者常误用「を」）。见第 3 课。
  • 活用后的声调会移动（例如辞书形和ます形的高低位置不同），本课只给辞书形标声调，活用形的声调以音频为参考；声调规律留到「声调进阶」专项。
