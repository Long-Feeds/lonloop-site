0 到 10

{% for id in ["n0","n1","n2","n3","n4","n5","n6","n7","n8","n9","n10"] %}{{ num(id) }}{% endfor %}
数字读法汉字
  • 4、7、9 有两种读法。单独报一个数字、需要对方听清时，常用「よん」「なな」「きゅう」；从一开始顺着数时，也常说「いち、に、さん、し、ご、ろく、しち、はち、く、じゅう」。具体用哪个还会随月份、时间和量词而定，例如 {{ m.jp("四月") }}（しがつ）、{{ m.jp("七月") }}（しちがつ）、{{ m.jp("九月") }}（くがつ）。遇到一个记一个即可。
  • 「し」「く」与「死」「苦」同音，这是生活中避开它们的常见原因之一。
  • 0：日常多说「ゼロ」（来自外语），也说「れい」（汉字「零」）。

11 到 99：和中文一样组合

数字读法汉字

十位、个位直接拼起来：14 = 十＋四 = じゅうよん。40、70、90 通常读よんじゅう、ななじゅう、きゅうじゅう。

百、千、万：音变要逐个记

{% for id in ["n100","n300","n600","n800","n1000","n3000","n8000","n10000"] %}{{ num(id) }}{% endfor %}
数字读法汉字
{% call m.callout("容易错的四点") %}

① 300 さんびゃく、3000 さんぜん：ん 后面浊化（ひゃく→びゃく，せん→ぜん）。

② 600 ろっぴゃく、800 はっぴゃく：变成促音＋半浊音。8000 はっせん同样有促音。

③ 100 读「ひゃく」，前面不加「いち」；1000 一般读「せん」（也有人说「いっせん」，初学先记せん）；但 10000 必须说「いちまん」，「まん」不能单独表示一万。

④ 日语和中文一样以「万」为单位进位：十万 じゅうまん、一百万 ひゃくまん。这一点中文母语者比英语母语者占便宜。
